## 阅读结论

两轮代理出口集合相同，但每轮均出现多个 IPv4，不能认定为固定出口。WebRTC 候选与 HTTP 观测不同，需要核实 UDP 接管路径。部分查询失败应按路径与来源进一步检查。该示例不提供长期可用率、精确位置或目标应用会话结论。

实际对照还需要核对节点备注、系统代理、客户端运行状态、网络特征及采样间隔；只有观测表相同不足以建立网络变化的因果结论。
